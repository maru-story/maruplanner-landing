# Maru Planner — Company Profile & Landing Page

Official company profile and marketing landing page for **Maru Planner** (`maruplanner.my.id`), a digital wedding invitation and guest management platform in Indonesia.

## Highlights
- **Apple-Style Scrollytelling:** Interactive 60fps frame-by-frame canvas animation driven by GSAP ScrollTrigger based on Google Flow visual renders.
- **Next.js 16 (App Router):** Fast, static prerendering with high SEO performance.
- **TailwindCSS 4:** Modern CSS-first design system matching the core Maru Planner dashboard tokens (Cream, Charcoal, Copper, Sage, Blush).
- **Hybrid Conversion:** Targeted at both Couples (15-section modular digital invitations, 1-click WhatsApp delivery) and Wedding Organizers (20fps offline-first QR check-in, real-time control room).

## Tech Stack
- **Framework:** Next.js 16 (React 19, TypeScript)
- **Animation:** GSAP 3.12, `@gsap/react`, HTML5 Canvas 2D
- **Icons:** `lucide-react`
- **Typography:** `Playfair Display` (Serif heading) & `Poppins` (Body)
